# Log!t Backup & Export Formats Specification

This document details the file formats, schemas, versioning rules, and safeguards used by Log!t for Google Drive cloud backups, JSON exports, and TXT exports.

---

## 1. Google Drive Cloud Backup Format

Log!t synchronizes backup archives to a private folder named `Logit` in the user's Google Drive.

### Schema Version 2 (Current)

### Backup Safeguards (Remediation of F-04)
1. **Query Failure Abort**: If `Logit.Storage.loadMovies()` returns `{ movies: [], error: '...' }`, the backup process immediately aborts. It **never** treats a network failure as an empty library.
2. **Empty Overwrite Protection**: If a user's local database currently has 0 movies, but an existing Google Drive backup exists that contains > 0 movies, Log!t refuses to overwrite the cloud backup unless explicitly confirmed, preventing catastrophic data wipeouts.
3. **Settings Restoration**: When restoring from Google Drive ([`js/drive.js`](file:///C:/Users/User/logit/js/drive.js#L264)), Log!t restores both the movie library **and** the user's `settings` (favorites and avatar).

## 2. Text Export / Import Format (TXT)

### Canonical Pipe-Delimited Format (Remediation of F-09)

Log!t uses a standard 7-field pipe-delimited format for `.txt` exports and imports:

```text
Title | Rating | Watch Date | Watch Status | Year | TMDB ID | IMDb ID
```

#### Example Output:
```text
Inception | 4.5/5 | 2024-05-10 | Rewatch · 2x | 2010 | 27205 | tt1375666
Oppenheimer | 5/5 | 2023-07-21 | 1st Watch | 2023 | 872585 | tt15398776
Dune: Part Two | 4.5/5 | 2024-03-01 | 1st Watch | 2024 | 693134 | tt15239678
The Substance | | 2024-10-15 | 1st Watch | 2024 | 933260 | tt17526714
```

#### Field Specifications:
| Index | Field | Description | Example |
|---|---|---|---|
| `0` | **Title** | Full movie title | `Inception` |
| `1` | **Rating** | Star rating out of 5 (or empty if unrated) | `4.5/5` |
| `2` | **Watch Date** | Date logged (`YYYY-MM-DD`) | `2024-05-10` |
| `3` | **Watch Status** | First watch or rewatch count | `Rewatch · 2x` |
| `4` | **Year** | Theatrical release year | `2010` |
| `5` | **TMDB ID** | The Movie Database numeric identifier | `27205` |
| `6` | **IMDb ID** | IMDb title identifier | `tt1375666` |

### Backward Compatibility
[`js/import.js`](file:///C:/Users/User/logit/js/import.js) automatically detects:
1. **Canonical 7-column format**: Detected when lines contain 6+ pipes (`|`).
2. **Legacy 5-column format**: Lines containing 4 pipes where the 3rd field is a TMDB or IMDb ID (`Title | Rating | ID | Date | Rewatch`).
3. **Unstructured lines**: Lines without pipes containing natural language titles and dates.

## 3. JSON Export Format

### Complete Metadata Export (Remediation of F-10)

Exporting to JSON via [`js/export.js`](file:///C:/Users/User/logit/js/export.js) outputs a complete JSON array of movies preserving all cached TMDB metadata:

```json
[
  {
    "id": "c1f72740-d293-4a15-b77c-a49ef84a1e94",
    "t": "Inception",
    "yr": "2010",
    "rt": 148,
    "g": "Action, Science Fiction, Adventure",
    "dr": "Christopher Nolan",
    "c": "Leonardo DiCaprio, Joseph Gordon-Levitt, Elliot Page",
    "lg": "en",
    "ct": "United States",
    "r": "5",
    "d": "2024-05-10",
    "w": "Rewatch · 2x",
    "sp": "/oYuLEt3zVCKq57qu2F8dT7NIa6f.jpg",
    "sc": "#1b2029",
    "pc": "#2c3340",
    "tmdb_id": "27205",
    "imdb_id": "tt1375666",
    "overview": "Cobb steals information from targets...",
    "created_at": "2024-05-10T14:20:00Z",
    "updated_at": "2024-05-10T14:20:00Z"
  }
]
```

Because `g` (genres), `dr` (director), `rt` (runtime), `c` (cast), `lg` (language), and `ct` (country) are included, re-importing this file never triggers external TMDB API lookups and preserves complete offline movie journal data.
